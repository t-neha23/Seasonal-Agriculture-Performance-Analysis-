# Seasonal-Agriculture-Performance-Analysis


## About the Project

This project focuses on understanding how agricultural performance changes across different seasons.

The dataset contains information related to **crops, farming practices, environmental conditions, resource usage, production, and economic performance**. The main aim is to explore the data and find useful patterns and differences between the **Kharif, Rabi, and Zaid** seasons.

The project uses data cleaning, exploratory analysis, visualization, and statistical testing to understand factors related to agricultural performance.

## Objectives

* Understand and explore the given agricultural dataset.
* Clean and prepare the data for analysis.
* Compare agricultural performance across different seasons.
* Identify important seasonal patterns and trends.
* Study the relationship between environmental conditions, resource usage, and crop yield.
* Compare crops, irrigation methods, and other relevant categories.
* Analyze differences in agricultural costs, revenue, and profitability.
* Use statistical methods and visualizations to support the findings.
* Draw useful conclusions from the analysis.

## Dataset

The dataset contains **4,000 records and 28 columns** covering different aspects of agriculture.

Some of the main information included in the dataset is:

* Crop and farming details
* Season
* Environmental conditions
* Water and resource usage
* Crop yield and production
* Cost and revenue
* Profitability
* Irrigation methods
* Geographical information

The analysis mainly focuses on three seasons:

* **Kharif**
* **Rabi**
* **Zaid**

## What I Did

### Data Exploration

I first explored the dataset to understand its structure, columns, data types, missing values, and basic statistics.

### Data Analysis

The data was then analyzed to compare agricultural performance across seasons. Different crops, irrigation methods, environmental factors, and economic measures were also studied.

### Statistical Analysis

Statistical tests were used to check whether the differences observed between seasons and other groups were actually significant.

The analysis included:

* Kruskal-Wallis Test
* Mann-Whitney U Test
* Scheirer-Ray-Hare Test
* Spearman Correlation
* Effect Size Analysis

### Visualization

Different charts and plots were created using Matplotlib and Seaborn to make the patterns in the data easier to understand.

## Key Findings

* Agricultural **yield varies across seasons**, with Kharif showing the highest overall yield compared with Rabi and Zaid.
* **Profitability also differs across seasons**, with Kharif performing better overall.
* **Crop type has a stronger influence on yield than season** in this dataset.
* Water usage showed the strongest relationship with yield among the factors analyzed, although the relationship does not prove that one directly causes the other.
* Differences between irrigation methods were statistically noticeable but relatively small.
* Per-hectare cost did not show a significant difference across seasons.
* The analysis did not find significant regional differences in the dataset.
